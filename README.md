# D-FF

## description
Designed the basic D(Data)-flip flop. At every positive clock edge the data is triggered using verilog.
## feature
single output
## files
d_ff.v : This code represents the RTL code for d_ff for design purpose.


tb_dff.v: Simulation can be done using this code.
## truth table
d | q(next)

0 | 0 

1 | 1 


## design & simulation
A very first create the design file with name d_ff and then give the input as d and clk and in output q at every clock edge pulse we should get the output. To get the behavioural simulation create the testbench file namely tb_dff and in DUT(design under test) connect all the wires.
